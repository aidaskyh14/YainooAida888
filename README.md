# เกมในสวนของยัยหนู — เวอร์ชันพร้อมเล่น

ไฟล์นี้เป็นเกมเว็บขนาดเล็กที่เล่นได้ครบตามวงจร:
ล็อกอิน → ปลูก 9 แปลง → รอเวลา → เก็บเกี่ยว → คราฟ 4 เมนู → แคปหน้าจอ

## เปิดทดลอง
เปิด `index.html` ในเว็บเบราว์เซอร์บนคอมพิวเตอร์ หรืออัปขึ้น GitHub Pages เพื่อเล่นบน iPad/Safari

## รหัสเจ้าของสำหรับทดลอง
- ชื่อสมาชิก: น้องไอด้าเซ็กซี่
- รหัส: YAINOO88

## ไฟล์ที่ต้องอัปขึ้น GitHub
อัปทั้งหมด 4 รายการนี้พร้อมกัน:
- `index.html`
- `style.css`
- `game.js`
- โฟลเดอร์ `assets`

ไม่ต้องอัปไฟล์ README.md ก็ได้ แต่เก็บไว้เป็นคู่มือได้

## สำคัญ
เกมบันทึกข้อมูลแยกตามชื่อสมาชิกใน Safari ของเครื่องนั้นด้วย Local Storage
ระบบรหัสเหมาะกับกิจกรรมระยะสั้น แต่ไม่ใช่การรักษาความปลอดภัยระดับธนาคาร
